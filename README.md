# Threat Intel & IOC Log

A running log of indicators of compromise (IOCs) identified during
hands-on security monitoring and investigation work. Each entry
documents the detection method, indicator, and recommended response —
no sensitive or internal data included.

## Structure
Each report follows a consistent format:
- Date & type of activity
- Indicator (IP, domain, hash, etc.)
- Detection method / tools used
- Recommended actions
- References
